# Import Norfund Capitalisation Data (Internal Function)

This internal function imports capitalisation agreements data for
Norfund DIM from an Excel file.

## Usage

``` r
import_norfund_capitalisation(cap_dim_filepath)
```

## Arguments

- cap_dim_filepath:

  A string. The path to the Excel file of agreement numbers of
  capitalisation of ordinary Norfund DIM.

## Value

A data frame containing the capitalisation agreements of ordinary
Norfund DIM.
