# Read PTA Disbursement level report into R from user-specified CSV file

Reads and processes the PTA Disbursement level report to produce a
cleaned dataset of disbursement level data

## Usage

``` r
read_pta_disbursement_level_from_csv(path)
```

## Arguments

- path:

  Path to the PTA Disbursement level CSV file

## Value

A cleaned data frame with one row per agreement
