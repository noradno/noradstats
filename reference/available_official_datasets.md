# List available dataset keys for official column names

Returns the dataset keys that can be used with
[`official_colname_map()`](https://noradno.github.io/noradstats/reference/official_colname_map.md)
and
[`rename_to_official()`](https://noradno.github.io/noradstats/reference/rename_to_official.md).

## Usage

``` r
available_official_datasets()
```

## Value

A character vector of dataset keys.
