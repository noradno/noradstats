# Import CIM Data from Excel (internal function)

This is an \*\*internal helper function\*\* and is not exported for
direct use. It reads a table of Climate Investment Mandate (CIM) data
from an Excel file.

## Usage

``` r
import_cim_data(cim_filepath)
```

## Arguments

- cim_filepath:

  A string. The path to the Excel file.

## Value

A data frame containing the CIM agreements.
